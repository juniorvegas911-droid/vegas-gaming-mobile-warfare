# Vegas Gaming: Mobile Warfare — Android PWA

## Cómo jugar en Android
1. Sube esta carpeta a un hosting HTTPS (por ejemplo GitHub Pages).
2. Abre `index.html`/la página desde Chrome en Android.
3. En Chrome usa **Añadir a pantalla de inicio**.
4. Se abrirá como una app independiente y funcionará offline después de la primera carga.

Nota: un archivo HTML abierto directamente desde `file://` no permite todas las funciones PWA; se recomienda HTTPS.
